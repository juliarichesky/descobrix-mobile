## Credencial demonstrativa local

O login atual é exclusivamente local e demonstrativo para a Sprint 1. Após
criar uma conta no aplicativo, use o e-mail cadastrado e a senha fixa
Descobrix@123 para acessar o protótipo. Essa credencial não representa uma
autenticação real, não deve ser usada por usuários reais e precisa ser
substituída por autenticação segura antes de qualquer distribuição pública.
Nenhuma senha de usuário é salva em SharedPreferences.
